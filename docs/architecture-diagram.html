NeuroAgent · System Map

A tool-augmented clinical agent, end to end

One repository, four moving parts: two React frontends, two FastAPI services, a ReAct agent core that investigates neurology cases through diagnostic tools, and the dataset & training pipeline that feeds it. Solid teal edges are runtime request flow; dashed slate edges are data artifacts.

600 v5 cases · 20 conditions 12 diagnostic tools 10-model registry · A100-40GB ReAct ≤ 15 turns cost-tracked (Medicare PFS)

ReAct reasoning loop

Linear transcript; working state is the conversation plus the final markdown assessment.

01
Think
visible reasoning text from the model
02
Act
OpenAI-style tool call — one of 12 tools, or referral (tool_name: null)
03
Observe
serialized ToolResult from MockServer; cost accrued
04
Reflect
templated prompt asks the model to update its reasoning
05
Assess
final markdown, extracted from ### Primary Diagnosis
Loop bound: steps 1–4 repeat up to 15 turns, then assessment is forced Prompt: base system prompt + hospital protocol context from RulesEngine Every step streams to the dashboard as SSE events and lands in the AgentTrace
