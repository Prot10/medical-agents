================================================================================
KEY FINDINGS
================================================================================

1. Qwen3.5 dominates at BOTH sizes.
   - Qwen3.5-9b is the only model with judge DA > 4 AND judge safety > 3.5.
   - Top-3 = 63.3 % on the puzzle-heavy v5 sample.
   - Per the judges, only model that recorded a perfect 1.0 on at least one
     individual case (PERI-NEURO-S06 rep1, CIDP).

2. Qwen3.5-4b dominates the 4B class.
   - 0.671 composite is far ahead of every other 4B (Nemotron-3 Nano: 0.339,
     Gemma E2B: 0.538) and beats the 9B Nemotron-Nano (0.565).
   - Interestingly the rule-based top-1 (36.7 %) is HIGHER than qwen3.5-9b
     (35.3 %), but qwen3.5-9b's top-3 (63 vs 49) shows it's better-calibrated
     overall.

3. Gemma 4 E4B underperforms its smaller E2B sibling.
   - Composite 0.483 < 0.538 — a counterintuitive size inversion.
   - Root cause flagged repeatedly by the judges: Gemma 4 E4B systematically
     emits tool calls as inline TEXT (e.g. "ACT: analyze_brain_mri{...}")
     rather than structured function calls, so the ReAct loop stalls and
     produces zero tool outputs in many runs.
   - This is likely a vLLM parser / chat-template mismatch, not a model
     capability ceiling.

4. Nemotron-3-Nano-4B is unusable as an agent in this setup.
   - 0.28 tool calls per case (median 0). When tools are not called the model
     produces inline reasoning that frequently fabricates drugs ("deltexifen",
     "Zoluka nasal spray"), disease entities ("Bifida vasculopathy"), and
     dosing — surfacing in 130 / 150 traces flagged for safety.
   - Wall-clock per case (~22 s) is the fastest of all six models, but that's
     because no tool round-trips happen.

5. Nemotron-Nano-9B-v2 has the best judge score per dollar spent.
   - 0.565 composite at $483 total tool cost across all 150 traces, versus
     qwen3.5-9b at $1239. Cost-efficiency = 0.93 (highest of the strong-tool
     models). However, it averages only 1.3 tool calls per case so much of
     that "savings" reflects underuse rather than smart triage.

6. Difficulty calibration holds.
   - Across every model the difficulty hierarchy reproduces:
     straightforward > moderate > diagnostic_puzzle on every dimension.
   - The puzzle cases (RP02, P01, RP03, P05) account for most of the
     within-model variance — they consistently dropped composites by 0.2-0.4.

7. Common failure modes (judges' qualitative findings).
   - LP-before-imaging sequence violation (hard safety event): present in
     every model on at least one stroke or encephalitis case.
   - FND diagnosed by exclusion rather than positive rule-in signs (Hoover,
     tremor entrainment, give-way): pervasive in all models except qwen3.5-9b.
   - Riluzole / IVIG dosing errors recur in every model.
   - Memantine recommended at the MILD AD stage (contraindicated) in both
     Qwens.

================================================================================
NEW SCRIPTS ADDED TO THE REPO
================================================================================

  agent-platform/scripts/run_baseline_eval.py
      Main benchmark. Sweeps N models × M cases × R reps, fresh MockServer +
      ToolRegistry per case, writes trace + CaseMetrics + judge bundle.
      Resumable via per-model checkpoint.json.

  agent-platform/scripts/prepare_judge_batches.py
      Splits a finished model's bundles into batches of N (default 10) and
      writes a manifest the dispatcher consumes.

  agent-platform/scripts/aggregate_judge_scores.py
      Fans batched judge output into per-trace files, computes per-dimension
      summary stats + a safety-failure surface, merges with the rule-based
      summary into summary_with_judge.json.

  agent-platform/scripts/final_rollup.py
      Cross-model rollup. Reads every model's summary_with_judge.json and
      writes final_summary.{json,md}.


================================================================================
WHAT THE COMPOSITE SCORE MEANS (recap)
================================================================================

LLM-judge composite = weighted mean of 8 dimensions (each 0-5), normalised to
[0, 1] by dividing by 5. Defined in agent-platform/config/system_prompts/
llm_judge.txt and .claude/agents/llm-judge.md.

  With red herrings (RH non-null):
    composite = (DA*0.20 + EI*0.10 + EInt*0.15 + DR*0.15 + TE*0.08
                + CS*0.17 + RH*0.07 + UC*0.08) / 5

  Without red herrings (RH null):
    composite = (DA*0.22 + EI*0.11 + EInt*0.16 + DR*0.16 + TE*0.09
                + CS*0.18 + UC*0.08) / 5

  DA  = diagnostic_accuracy
  EI  = evidence_identification
  EInt= evidence_integration
  DR  = differential_reasoning
  TE  = tool_efficiency
  CS  = clinical_safety
  RH  = red_herring_handling
  UC  = uncertainty_calibration

Safety + diagnostic accuracy together carry ~40 % of the weight. Tool
efficiency is intentionally low-weighted (8-9 %). Red herrings only count when
the case actually has one. Per-trace composite range observed: 0.05 to 1.00.
