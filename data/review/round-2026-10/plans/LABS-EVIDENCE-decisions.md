# Lab evidence decisions (25 Oct 2026)

Commit 317e46db made an `interpret_labs` order return only the stored panels it names. `notes/labs-evidence-unserved-2026-10-24.txt` lists 143 required or recommended criteria whose `expected_evidence` cites an abnormal result their own order (first alternative) no longer returns. This file covers the 117 outside SE (SE handled separately).

Rule applied (Andrea's standing rule: decide for dataset quality, record why): when the result is the criterion's point (its label or rationale, a must, the differential, the key evidence or a red herring relies on it as coming from this order), the order is made to return it. Where the assay belongs in the same first-line order clinically and the case's condition already requires such case-specific assays, it is added to every alternative (a scoring change); otherwise a new first alternative names it and the previous order is kept as an alternative, so any call that matched before still matches. When the result is incidental, the evidence is trimmed to what the order returns and the stored panel stays servable to an agent that orders it.

Scoring column: `yes` = coverage stricter; `cost reference only` = coverage unchanged, but the policy's cost reference (sum of the first alternatives of required criteria) now prices the fuller order, which can only raise cost efficiency; `no` = no effect on any reward component.

## CENTRAL

- Vocabulary: no `interpret_labs` assay orders an HBV viral load (HBV DNA). HEP-ENC-S05 stores HBV DNA 340 IU/mL on tenofovir and a must acts on it; only an order for `hepatitis_B_surface_antigen` would return that panel, by its name. Request an `HBV_DNA` term (CPT 87517) with its library normal and the `tool_io.py` mirror, then rename the stored panel.
- Lab matcher: a urinalysis panel's `Urine WBC` / `Urine RBC` rows answer a `CBC` order (ISCH-STR-P03 received its urinalysis from a CBC order). `urinalysis` is name-only, but the CBC components match urine rows.
- Lab matcher: the unit `mg` (in `mg/dL`) is normalised to `magnesium` by `_PHRASES`, so `mentions()` reads any evidence with a mg/dL value as citing magnesium (probe false positives on FEPI-TEMP-RP01, SYNC-CARD-S05).
- Class beyond this list: the same label/order gap exists in the other cases of these conditions with normal values (the list flagged only abnormal ones): ALS `action-5` (CMP, ESR/CRP in the label, not the order), HEP-ENC `action-1` (CRP in the label), SAH baseline (troponin read in key evidence), ALZ-EARLY lipids/HbA1c.
