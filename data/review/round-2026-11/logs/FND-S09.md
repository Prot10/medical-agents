## Changes
The literature step is gone (class LIT). A 12-lead ECG is now required and in the stop rule with the examination, because his episodes include apparent loss of responsiveness (NICE CG109); it returns a case-specific normal ECG (sinus 86/min, QTc 431 ms) instead of the shared template. Video-EEG is now recommended rather than optional, because an episode was witnessed on the ward (ILAE 2013; AAN 2025). The diagnosis label says hazardous alcohol use instead of alcohol use disorder (AUDIT 14, WHO hazardous zone; no DSM-5 AUD criteria documented). The stored labs are split into named panels, so each lab order returns only what it names (a CBC order no longer returns the post-event prolactin or blood alcohol); the CBC gained a normal MCV and platelet count, and the raised GGT now carries a short interpretation. Criteria and follow-ups are reordered to the condition order.
