## Changes
No reviewer note. ALZ-EARLY class changes: perfusion SPECT is labelled waste (NICE NG97: SPECT only substitutes for an unavailable FDG-PET); FDG-PET stays the optional criterion for the bvFTD question; the stop rule allows no extra uncredited action (max 0). Because of that, the genetics step was split: the FTD gene panel and the APP/PSEN1/PSEN2 panel are now two optional criteria, so an agent that orders both, as the criterion label always asked, is credited for both instead of being penalised for the second. The follow-up list shows the credited steps first (neuropsychology, FDG-PET, both gene panels, drug check), then the amyloid PET that is only an alternative to the CSF already in the initial results, then the on-request reports, none deleted. The performance-status report is rewritten from her history. Diagnosis and musts unchanged.
Pass 1 (verifier): the on-request perfusion SPECT report now reads as a sentence; the two gene-panel criteria have distinct labels and citations, and the difficulty summary lists both panels as separate optional steps.
Pass 2 (verifier): the head CT that answers an off-pathway CT order no longer calls the frontal atrophy age-related; it describes the same frontal-predominant pattern as the MRI.
Pass 3 (verifier): perfusion SPECT is no longer labelled waste here; NICE NG97 names FDG-PET or perfusion SPECT as equal options when frontotemporal dementia is suspected, so the FTD-question imaging step now accepts either one (one is enough, a second is uncredited). The SPECT report carries its own regional values.
Condition audit: the bedside screen scores (MMSE/MoCA totals, item losses, recall with cues, clock and copy results, fluency counts) were taken out of the neurological examination, where the agent saw them before ordering the cognitive assessment; they remain in the cognitive assessment report.
